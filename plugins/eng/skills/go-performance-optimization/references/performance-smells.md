# Performance Smells

- Optimizing without measurement.
- Huge rewrite before identifying the bottleneck.
- SQL query in a handler "for speed".
- Domain importing infra.
- Bypassing the repository interface.
- `unsafe` or reflection tricks without proof.
- `fmt.Sprintf` / string concatenation in a hot loop.
- `[]byte(s)` / `string(b)` conversion repeated in a loop.
- Slices/maps grown without capacity when size is known.
- Interface boxing inside inner loops.
- `sync.Pool` on a cold path.
- Goroutine per item with no bound.
- Fire-and-forget goroutine with no stop/wait.
- Channel send without a `ctx.Done()` escape.
- Buffered channel sized by guesswork.
- Lock held around IO, serialization, or CPU-bound computation.
- Cache whose hit rate has never been measured; cache keyed by a per-request unique value.
- Cache with no eviction or size bound.
- Reporting a throughput win without checking what happened to p99.
- Storing `c.Params()`/`c.Query()`/`c.Body()` values past the handler without copying.
- Broad transaction.
- N+1 repository calls.
- DB pool exhaustion; `MaxConns` sized to app concurrency instead of DB capacity.
- No timeout; no cancellation.
- Benchmark that measures setup instead of target.
- Benchmark with unrealistic input.
- Single-run benchmark claims; ignoring benchstat `~`.
- GC knob tuning before allocation reduction.
- Claiming improvement without before/after data.
